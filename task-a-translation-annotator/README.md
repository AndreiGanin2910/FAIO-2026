# Кто дал оценку

Два лингвиста оценивали качество переводов между казахским и русским языками. Требуется определить вероятность того, что каждую оценку из тестовой выборки поставил `person2`.

**Метрика:** ROC-AUC.  
**Leaderboard:** `0.7622`.

## Решение

- статистические и лексические признаки для оригинала, эталона и двух переводов;
- Logistic Regression, Extra Trees и LightGBM;
- COMETinho для оценки качества переводов;
- групповая валидация по исходному предложению;
- специальная коррекция пар с одинаковым `original`;
- финальный blend с весом COMET `0.25`.

Положите `train.csv` и `test.csv` рядом с `solution.ipynb` и выполните **Run All**. На выходе будет создан `solution.csv` с колонками `id` и `probability`.
