# Обратная нормализация текста

Задача поиска семиотических фрагментов в русских, казахских и смешанных предложениях. Каждому токену назначается BIO-метка одного из классов: `CARDINAL`, `ORDINAL`, `DECIMAL`, `DATE`, `TIME`, `MEASURE`, `EMAIL` или `WHITELIST`.

**Метрика:** точный span-level F1.  
**Сохранённый leaderboard:** приблизительно `0.914`.

## Решение

- `cointegrated/rubert-tiny2` для token classification;
- расширение словаря казахскими и предметными токенами;
- основное обучение и дополнительная быстрая адаптация;
- Viterbi-декодирование с ограничениями BIO;
- проверка структуры и допустимых меток перед сохранением.

Положите `train.csv` и `test.csv` рядом с `solution.ipynb` и выполните **Run All**. Итоговый `solution.csv` содержит `sent_id`, `token_id` и `label`.
